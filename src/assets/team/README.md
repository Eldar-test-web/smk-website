# Member portraits

Drop each leadership portrait in this folder using the file name below. Vite picks them up at
build time through `import.meta.glob` in `src/data/team.ts`, so no code change is needed.

| File name                     | Member                |
| ----------------------------- | --------------------- |
| `huseyn-abdullayev.jpg`       | HÜSEYN ABDULLAYEV     |
| `cavidan-haciyev.jpg`         | CAVİDAN HACIYEV       |
| `murad-aslanli.jpg`           | MURAD ASLANLI         |
| `tunar-huseynqulizade.jpg`    | TUNAR HÜSEYNQULIZADƏ  |

Any member whose file is missing falls back to a neutral initials panel, so the page always
renders cleanly.

Recommended: portrait crop, 4:5 ratio, at least 800 x 1000 px, JPG or PNG.
